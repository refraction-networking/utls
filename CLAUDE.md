# CLAUDE.md

This repository is maintained with the help of AI coding agents. The full
operating manual — architecture, the one rule about `internal/tls`, and the
step-by-step procedures for following a new Go release, adding a fingerprint,
and extending the API — is in **[AGENTS.md](AGENTS.md)**. Read it before making
changes.

Quick reminders:

- All `crypto/tls` coupling lives in `internal/tls`, which is GENERATED by
  `upstream/sync.sh`, not authored. Put your code in `u_*.go` files or the root
  package; touch mirrored files only via marked `[uTLS]` hunks.
- `go test ./...` runs the upstream crypto/tls suite against the mirror plus the
  uTLS tests. `upstream/sync.sh check` guards the patch. Keep `go vet ./...` clean.
- Do not reintroduce uTLS-specific copies of `tls.Config`/`tls.ConnectionState`;
  the public API speaks the standard types.
- uTLS is a TLS library: no HTTP clients, RoundTrippers, proxies or HTTP/2
  handling. ALPS settings are returned as opaque bytes for the caller's stack.
