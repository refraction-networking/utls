# v1 → v2 removal audit

This is the complete audit of the exported API of uTLS v1 (refraction-networking/
utls at ff1b50f, the v2 base) against v2. It was produced mechanically with a
syntax-level extractor of exported declarations over v1's non-test sources
(the v2 API gate itself is type-checked; see api_test.go), then classified by
hand. Counts: 693 v1 declarations; 61 kept
under the same name; 168 are crypto/tls API that v2 takes or returns as the
standard types (or re-exports, e.g. the cipher-suite and version constants);
464 removed. Every removed identifier falls in one of the groups below, each
with its replacement or the reason there is none. The full list is in the
appendix.

v2 is published as module `github.com/refraction-networking/utls/v2`, so v1
users are unaffected until they choose to migrate (docs/MIGRATION.md).

| Group (v1) | v2 replacement / reason |
|---|---|
| uTLS copies of crypto/tls (`Config`, `Conn`, `ConnectionState`, `ClientSessionState`, `SessionState`, `QUIC*`, `Dial`, `Listen`, `Server`, `CertificateRequestInfo`, errors, …) | the `crypto/tls` types themselves. Server-side entry points (`Server`, `Listen`, `NewListener`, `QUICServer`) are gone: v2 is a client; use crypto/tls on the server. |
| `TLSExtension` stream methods: `X.Len`, `X.Read`, `X.Write`, `X.UnmarshalJSON` on every extension type; `TLSExtensionWriter`, `TLSExtensionJSON`, `*JSONUnmarshaler`, `ClientHelloSpec.{FromRaw,ImportTLSClientHello,ImportTLSClientHelloFromJSON,ReadCipherSuites,ReadCompressionMethods,ReadTLSExtensions,UnmarshalJSON}`, `ExtensionFromID`, `Fingerprinter` | the interface's methods are unexported so new extension kinds never break downstream. Parse bytes with `ParseClientHello`; store specs as data with `ExportProfile`/`ParseProfile` (versioned JSON). |
| Handshake internals: `PubClientHelloMsg`, `PubServerHelloMsg`, `PubClientHandshakeState`, `TLS12OnlyState`, `TLS13OnlyState`, `PubCipherSuite*`, `KeyShares*`, `KeySharePrivateKeys`, `KemPrivateKey`, `KeyShare.ToPrivate`, `PskIdentities`, `TicketKey(s)`, `FinishedHash`, `UnmarshalClientHello/ServerHello`, `InnerClientHello`/`OuterClientHello`, `ClientHelloBuildStatus`/`BuildByGoTLS`/`BuildByUtls`/`NotBuilt`, `CertificateRequestMsgTLS13`, `Initializable` | not exposed. The intents behind them: `SetClientHelloHook` (`ClientHelloContext.Raw/Random/SessionID/EphemeralKey`), `ServerHelloRaw`, `ServerKeyShareGroup/Data`, `ClientHelloRaw`. |
| Two-phase building: `UConn.BuildHandshakeState`, `BuildHandshakeStateWithoutSession`, `MarshalClientHello`, `MarshalClientHelloNoECH`, `SetClientRandom`, `ApplyConfig`, `SetTLSVers`, `UtlsAboutToCall`/`CalledByGoTLS`/`CalledByULoadSession`/`NeverCalled` | the hook runs on the final hello with binders recomputed afterwards; versions come from `Config.Min/MaxVersion` and the spec. |
| `UConn.SetSNI`, `RemoveSNIExtension` | `Config.ServerName` (an empty `SNIExtension{}` uses it; IP literals are omitted as RFC 6066 requires); omit `SNIExtension` from the spec to send no SNI. |
| `UConn.GetUnderlyingConn`/`SetUnderlyingConn` | `NetConn()`; swapping the transport mid-connection is not supported. |
| `UConn.GetOutKeystream` (TapDance), `MakeConnWithCompleteHandshake` | `HandOff()` returns the TLS 1.3 keys, IVs, secrets and sequence numbers. Constructing a Conn from foreign key material is not offered (no current user; easy to misuse). |
| `Conn.ConnectionMetrics`, `ConnectionMetrics` | removed (no downstream user found). |
| Session plumbing: `ClientSessionState.Set*`/getters, `MakeClientSessionState`, `UConn.SetSessionState`, `SetSessionCache`, `SetSessionTicketExtension`, `SetPskExtension`, `DidTls12Resume`, `LoadSessionTrackerState`, `ISessionTicketExtension`, `SessionTicketExtension.{GetSession,GetTicket,InitializeByUtls,IsInitialized}`, `SessionTicketExtInitialized`/`AllSet`, `PreSharedKeyCommon`, `PskExt*`, `ErrEmptyPsk`, `{Utls,Fake,Unimplemented}PreSharedKeyExtension` | sessions from any std `ClientSessionCache` resume automatically; `SetSession(*tls.ClientSessionState)`; forged/out-of-band sessions: `SetSessionParams(ClientSessionParams)`; `ConnectionState().DidResume`. `PreSharedKeyExtension{}` marks where pre_shared_key goes; uTLS fills it. |
| Renamed extensions: `UtlsCompressCertExtension`, `FakeRecordSizeLimitExtension`, `ApplicationSettingsExtensionNew`, `UtlsExtendedMasterSecretExtension`, `GREASEEncryptedClientHelloExtension`/`BoringGREASEECH`/`GREASEECHExtension`/`ECHExtension`/`UnimplementedECHExtension` | `CompressCertificateExtension`, `RecordSizeLimitExtension` (now negotiated and enforced), `ApplicationSettingsExtension{CodePoint: ALPSCodepointNew}`, `ExtendedMasterSecretExtension`, `EncryptedClientHelloExtension{GREASE: true}` (real ECH via `Config.EncryptedClientHelloConfigList`). |
| `FakeDelegatedCredentialsExtension`/`DelegatedCredentialsExtension`, `StatusRequestV2Extension`, `FakeTokenBindingExtension` | `GenericExtension{Id, Data}` (never negotiated by uTLS; the presets that send delegated_credentials do it this way). |
| `NPNExtension`, `FakeChannelIDExtension`, `Hello360_*` | removed: uTLS cannot negotiate NPN or Channel ID, so offering them makes handshakes with servers that accept them fail. `ParseFingerprint("360")` returns an explanatory error. |
| QUIC transport-parameter encoders (`TransportParameters`, `ActiveConnectionIDLimit`, `InitialMax*`, `MaxIdleTimeout`, `GREASEQUICBit`, `GREASETransportParameter`, `VersionInformation`, `PaddingTransportParameter`, `FakeQUICTransportParameter`, `VERSION_*`, …), `UQUICClient`/`UQUICConn`, `UConn.QUIC*` | `QUICClient`/`QUICConn` on the standard crypto/tls QUIC types; transport parameters are the QUIC stack's (`SetTransportParameters(raw)`), as with crypto/tls. |
| Versioned fingerprints older than the current presets (`HelloChrome_58` … `_133` incl. `_PSK`/`_Shuffle`/`_PQ` variants, `HelloFirefox_55` … `_120`, `HelloEdge_85/106`, `HelloIOS_11_1/12_1/13`, `HelloSafari_16_0`) | removed: stale parrots are themselves fingerprintable. Use `*_Auto`, a captured preset, `ParseFingerprint`, or keep an old spec as a profile (`ParseProfile`). PSK, shuffling and PQ are no longer separate IDs: presets shuffle and offer PQ as the browser does, and PSK is used whenever a session is available. |
| Non-standard constants: `FAKE_*`/`DISABLED_*`/`OLD_*` cipher suites, `FakeCurve*`, `FakeFFDHE*`, `Fake*With*` signature schemes, `CurveSECP*`/`CurveX25519` aliases, `X25519Kyber*`, `P256Kyber768Draft00`, `HPKE_*_ID`, `HPKERawPublicKey`, `PskModeDHE`/`PskModePlain`, `GREASE_MAX_MULTIPLIER` | specs take raw numbers (`[]uint16` suites, `CurveID(n)`, `SignatureScheme(n)`); IANA names live in `dicttls`. Kyber drafts are obsolete (X25519MLKEM768 is supported). |
| `EnableWeakCiphers` (global) | removed: offering a suite is a spec decision; negotiating suites crypto/tls does not implement is impossible either way. |
| `Roller`, `NewRoller`, `Roller.Dial` | removed (a caller-side retry loop over `ParseFingerprint` results). |
| `UTLSIdToSpec`, `ShuffleChromeTLSExtensions`, `ReuseHybridAndClassicalKeyShares`, `GetBoringGREASEValue`, `AlwaysPadToLen`, `UtlsPaddingExtension.Update`, `ClientHelloSpec.AlwaysAddPadding` | `ClientHelloID.Spec()`; `Profile.Shuffle = "chrome"`; `KeyShareExtension.ReuseClassicalFromHybrid`; GREASE is per connection, BoringSSL-style; `BoringPaddingStyle`. |
| `PRNGSeed`, `PRNGSeedLength`, `Weights` | `[32]byte` seeds from `NewPRNGSeed`, `SeededRandomized(seed, *RandomizedWeights)`. |
| `ErrUnknownClientHelloID`, `ErrUnknownExtension` | errors returned by `ParseFingerprint` / `ParseClientHello` (and `ErrNoSpec` at handshake). |
| `fipsonly` package | removed: it imported std-internal packages and could not build outside GOROOT. |
| `examples/` (v1 API) | `example_test.go` (compile-checked `Example` functions) and `downstream_test.go`. |

Restored from v1 unchanged: `LICENSE`, `SECURITY.md`, `CONTRIBUTING.md`, logos,
and the `dicttls` package (IANA constants; public, no crypto/tls coupling).
